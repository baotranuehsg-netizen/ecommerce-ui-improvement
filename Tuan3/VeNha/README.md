# Bài tập CSS cơ bản

- Sinh viên: Trần Quốc Bảo
- MSSV: 31241028457
- Thư mục nộp: `Tuan3/VeNha`

Mở `index.html` để xem và truy cập từng bài.

## Nội dung

- `BaiTap1.html`: liên kết hai trò chơi và file Word gồm 33 ảnh minh chứng do sinh viên đã hoàn thành.
- `BaiTap2.html`: định dạng văn bản, text shadow, background lặp và overflow.
- `BaiTap4.html` đến `BaiTap7.html`: các bài bắt buộc trong lựa chọn 3b.
- `BaiTap8a.html` và `BaiTap8b.html`: hai bài mở rộng lấy dữ liệu từ các liên kết Google Drive trong đề.
- Font Awesome 5 được dùng từ CDN ở các trang.
- Logo BIT trong Bài 2 và Bài 5 lấy từ ảnh công khai do sinh viên cung cấp trên Facebook.

## Ghi chú nguồn

- CSS Diner: https://flukeout.github.io/
- CSS Speedrun: https://css-speedrun.netlify.app/
- Font Awesome 5 CDN: https://cdnjs.cloudflare.com/ajax/libs/font-awesome/5.15.4/css/all.min.css
- Dữ liệu bài 8: các liên kết `css1` và `css2` trong file đề.
