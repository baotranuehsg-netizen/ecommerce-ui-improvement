## Mục tiêu

Dự án này tổng hợp kết quả thực hiện ba bài thực hành JavaScript.
Mục tiêu của bài là vận dụng JavaScript để xử lý dữ liệu, thay đổi
nội dung trang web, xử lý sự kiện người dùng và tạo các chức năng
tương tác cơ bản.

## Nội dung bài thực hành

### Lab 08 - JavaScript 1: Language Foundations

Thực hành cú pháp JavaScript cơ bản, biến, hàm, String, Date, Math,
Array, Object và Browser Console.

[Truy cập Lab 08](Lab08/)

### Lab 09 - JavaScript 2: DOM and Events

Thực hành lựa chọn và thay đổi phần tử DOM, xử lý sự kiện, làm việc
với biểu mẫu, kiểm tra dữ liệu và sử dụng công cụ Debugger.

[Truy cập Lab 09](Lab09/)

### Lab 10 - JavaScript 3: jQuery

Thực hành jQuery Selectors, Events, DOM, Animation, GET Request và
xử lý kết quả bằng jqXHR.

[Truy cập Lab 10](Lab10/)
