# Lab 07 – CSS nâng cao

- **Sinh viên:** Trần Quốc Bảo
- **MSSV:** 31241028457
- **Lớp học phần:** Phát triển ứng dụng TMDT – 26C1INF50902702 – ST5

## Mục tiêu

Thực hành cách tổ chức bố cục trang web, điều chỉnh giao diện theo chiều rộng
màn hình, tạo hiệu ứng CSS và sử dụng hệ lưới Bootstrap.

## Nội dung thực hành

| Exercise | Nội dung |
| --- | --- |
| 7.1–7.4 | Document flow, định vị tương đối, định vị tuyệt đối và z-index |
| 7.5–7.9 | Float, clear và đặt chú thích chồng lên ảnh |
| 7.10–7.13 | Bố cục hai và ba cột, media queries, viewport và menu mobile |
| 7.14–7.18 | Transforms, transitions, filters và animations |
| 7.19 | Bootstrap grid, navbar, panel, jumbotron và cột lồng |

## Cấu trúc thư mục

- `index.html` — Trang chủ và danh sách liên kết đến các Exercise.
- `lab07-exercise*.html` và `lab07-exercise*.css` — Mã nguồn các bài thực hành.
- `images/` — Ảnh dùng trong Lab và ảnh đại diện.
- `bootstrap/` — Thư viện Bootstrap đi kèm bộ mẫu.

Exercise 7.12 và 7.13 dùng chung `lab07-exercise12.html` và hai file CSS
desktop/mobile. Exercise 7.13 bổ sung viewport và menu dạng hộp chọn.

## Cách xem bài

Mở `index.html` trong trình duyệt, sau đó chọn bài trong mục **Danh sách bài
thực hành**. Với 7.12 và 7.13, thay đổi chiều rộng cửa sổ để xem bố cục
desktop và mobile.
